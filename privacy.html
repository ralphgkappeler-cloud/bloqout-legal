Politique de Confidentialité — BloqOut

Dernière mise à jour : 30 avril 2026

1. Présentation

BloqOut (« l'Application ») est une application mobile de blocage d'applications avec défis physiques et mentaux, développée et éditée par Gless Kappeler (« nous », « notre »).

Cette politique de confidentialité explique quelles données sont collectées, comment elles sont utilisées et quels sont vos droits.

2. Données collectées

2.1 Données stockées localement sur votre appareil

BloqOut ne dispose pas de serveur propre. Les données suivantes sont stockées uniquement sur votre appareil, via AsyncStorage :

  • Vos objectifs de blocage (nom de l'application, type de défi, durée de déblocage)
  • Vos blocages rapides en cours (nom de l'application, durée restante)
  • Vos plages horaires de blocage (nom de l'application, heures, jours de la semaine)
  • Vos statistiques d'utilisation (nombre de victoires, répétitions physiques, défis mentaux)
  • Votre plan de coach sportif (objectif, niveau, jours, équipement, blessures déclarées)
  • Vos préférences (langue, thème, options d'abonnement)
  • Le statut de vos jokers

Ces données ne nous sont jamais transmises et restent sur votre téléphone. La désinstallation de l'application les efface définitivement.

2.2 Données transmises à des tiers

Google Gemini (Google LLC)
Lorsque vous utilisez les défis de langue ou le coach sportif IA, certaines données sont envoyées à l'API Google Gemini pour générer du contenu :

  • Défis de langue : votre langue source, votre langue cible et la catégorie sélectionnée
  • Coach sportif : votre objectif (perte de poids, muscle, etc.), votre niveau, vos jours disponibles, votre équipement, vos blessures déclarées librement (champ texte)

Aucun identifiant personnel (nom, email, identifiant d'appareil) n'est inclus dans ces requêtes. Les données envoyées peuvent toutefois contenir du texte que vous saisissez librement dans le champ « Blessures / limitations ». Nous vous recommandons de ne pas y inscrire d'informations médicales sensibles ou identifiantes.
→ Politique de confidentialité Google : https://policies.google.com/privacy

Expo (Expo Inc.)
L'application est construite avec le framework Expo. Expo peut collecter des données techniques anonymes liées au fonctionnement de l'application (crashes, diagnostics).
→ Politique de confidentialité Expo : https://expo.dev/privacy

RevenueCat (RevenueCat Inc.) (uniquement si vous souscrivez à un abonnement payant)
Les achats in-app sont traités via Apple App Store ou Google Play Store, et gérés par RevenueCat. RevenueCat reçoit un identifiant anonyme d'achat pour vérifier votre statut d'abonnement. Aucune donnée bancaire ne transite par BloqOut.
→ Politique de confidentialité RevenueCat : https://www.revenuecat.com/privacy

Apple App Store / Google Play Store
Les paiements d'abonnement sont traités directement par Apple ou Google selon leur propre politique de confidentialité.

GitHub (GitHub Inc.) (uniquement si vous saisissez un code promo)
Les codes promo sont vérifiés contre une liste publique hébergée sur un Gist GitHub. Cette requête est anonyme et ne contient aucune donnée vous concernant autre que le code que vous saisissez.

3. Permissions requises

Android

  • Accès à l'usage des applications (PACKAGE_USAGE_STATS) : nécessaire pour détecter quelle application est au premier plan et déclencher le blocage. Ces données ne quittent jamais votre appareil.
  • Caméra : utilisée uniquement pour la détection de mouvements en temps réel lors des défis physiques (pompes, squats…). Les images ne sont pas enregistrées ni transmises.
  • Notifications : pour vous avertir de la fin d'un déblocage et vous rappeler vos défis quotidiens.

iOS

  • Caméra : même usage que décrit ci-dessus.
  • Notifications : même usage que décrit ci-dessus.
  • Family Controls (si l'autorisation Apple est accordée) : utilisée pour le blocage natif des applications. Aucune donnée d'usage n'est transmise hors de votre appareil.

4. Données des mineurs

BloqOut n'est pas destinée aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de données personnelles provenant de mineurs.

5. Sécurité

Vos données étant stockées localement sur votre appareil, leur sécurité dépend de la sécurité de votre téléphone (code PIN, biométrie, etc.). Nous vous recommandons de maintenir votre système à jour.

6. Vos droits (RGPD)

Si vous êtes résident de l'Union Européenne, vous disposez des droits suivants :

  • Droit d'accès : consulter les données vous concernant
  • Droit de suppression : supprimer vos données (via la désinstallation de l'app, qui efface toutes les données locales)
  • Droit de rectification : corriger les données vous concernant
  • Droit d'opposition : vous opposer à certains traitements
  • Droit à la portabilité : recevoir vos données dans un format structuré (sur demande)

Pour exercer ces droits ou pour toute question, contactez-nous à : bloqoutsupport@proton.me

Vous disposez également du droit d'introduire une réclamation auprès de la CNIL (https://www.cnil.fr) si vous estimez que vos droits ne sont pas respectés.

7. Modifications

Nous pouvons modifier cette politique à tout moment. En cas de modification substantielle, vous en serez informé via une notification dans l'application. La date de dernière mise à jour est indiquée en haut de ce document.
